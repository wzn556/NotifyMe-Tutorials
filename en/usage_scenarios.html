    SmsForwarder

    Github: https://github.com/pppscn/SmsForwarder

    • Create Senders: Choose Webhook to create Senders
    • Method: POST
    • Webhook Server：https://send.notifyme-f7507.521933.xyz
    • Replace the content in the quotation marks following to in the following Params (select a specific Params based on Sms Forward or App Forward) with the copied token in NotifyMe (NotifyMe-Settings/Share Token)
    • The definition of items in the Params and Advanced Use can be found in JSON Interpretation

    Sms Forward

    Qinglong

    Github：https://github.com/whyour/qinglong

    进入System Settings/Notification Settings进行通知设置：

    • Notification Method: Choose Custom Notification

    • webhookMethod: Choose POST

    • webhookContentType: Choose application/json

    • webhookUrl：https://send.notifyme-f7507.521933.xyz

    • webhookBody：

    Replace the content in the quotation marks following to with the copied token in NotifyMe (NotifyMe-Settings/Share Token).

    data:{"data":{"body":"$content","group":"Qinglong","title":"$title"},"priority":"normal","to":"dEHbLerlTyy_U_W1VDbPRv:APA91bGmZH9G70laPXXyjHoOKaWj1m_IcdP46dtkWYTQ6G7VhMZajV2v-AYE-5kzcN_tez3oBGJ_suqJFXNJDyTjK0VbjutvuLk4oVWhRvnvvkgzPOwhoPCBfzdQ2EKGnmXeG-7wlHcr","ttl":86400}
    • The definition of items in the webhookBody and Advanced Use can be find in JSON Interpretation.
