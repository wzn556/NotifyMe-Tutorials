    同步剪贴板

    其他设备同步至 NotifyMe

    • 向 NotifyMe 发送消息时将actionType设置为4即可。

    • 已提供 Quicker 向 NotifyMe 同步的示例动作。

    请求示例

    {
    "data": {
        "uuid": "CWYMVYWQHoPGXEkh9yP5Nd",
        "ttl": 86400,
        "priority": "high",
        "data": {
            "title": "剪贴板同步",
            "body": "${clipboard}",
            "group": "剪贴板同步",
            "iconType": 2,
            "actionType":4,
            "bigText":true
        }
    }
}

    NotifyMe 同步至其他设备

    • 在 配置/HTTP 中添加 HTTP 请求，状态栏中添加NotifyMe的 同步剪贴板 磁贴。点击磁贴，再点击对应的 HTTP 请求名称即可发送请求，以同步剪贴板。
    • 可使用变量${clipboard}（剪贴板内容）、${time}（发送请求的时间，例如2025-07-21 16:49:13）、${timestamp}（发送请求的时间戳）。
    • 在部分设备上，无法直接读取剪贴板，出现读取剪贴板失败时，点击该文字可重新读取剪贴板（剪贴板为空时也可能显示读取失败，请检查确认是否已复制要同步的文本）。
    • 出现异常时，可尝试将磁贴移除再重新添加。

    请求示例

    • 名称：设备1
    • URL：https://aaa.bbb.com
    • 请求方法：POST
    • Content Type：application/json
    • 请求内容：
    {
    "test": "1234",
    "time": "${time}",
    "timestamp": "${timestamp}",
    "clipboardContent": "${clipboard}"
}
    • Header
    {
    "Content-Type": "application/json",
    "Authorization": "Bearer xyz123",
    "User-Agent": "NotifyMe/1.0"
}

    同步至 Quicker

    • 名称：Quicker

    • URL：https://push.getquicker.cn/to/quicker

    • 请求方法：POST

    • Content Type：application/json

    • 请求内容：

    {
    "toUser":"aabbcc@email.com",
    "code":"xxxxxxxxxx",
    "operation":"copy",
    "data":"${clipboard}"
}
