    HMS 推送

    HMS 推送是由华为提供的消息推送服务，但其在非华为设备上也可使用（须安装 HMS Core）。

    • HMS 推送支持所有的键值对，具体见进阶使用。
    • 非华为/荣耀设备（即系统非 EMUI 或 HarmonyOS）使用HMS推送，需下载 HMS Core，同时须注意以下事项。
      • 需授予 HMS Core 关联启动权限，避免 HMS Core 拉起 NotifyMe 失败导致消息延迟或遗漏。
      • HMS Core 需打开 允许应用后台运行，关闭 电池优化，授予 自启动权限。
      • 无需使用HMS Push模块。但如果使用HMS Push对HMS Core进行了优化（HMS Core签名被改变），则必须对NotifyMe也进行优化。
